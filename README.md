## Key Features

- Layer 1: Pattern Detection – Finds structured identifiers like SSNs, credit cards, and emails.
- Layer 2: Entity Recognition – Identifies people, organizations, and addresses using AI models.
- Layer 3: Contextual Reasoning – Uses an AI agent to judge if something is actually sensitive in context.
- Layer 4: Cross-Document Intelligence – Connects the dots across files to reveal mosaic identities.

> [!IMPORTANT]
> Clark runs entirely on your infrastructure. No data ever leaves your machine.

---

## The Mosaic Effect

"The pieces are harmless. The picture isn't."

Clark detects when fragments of identity—scattered across different files—form a complete, re-identifiable profile. This is the Mosaic effect, and it's what makes Clark more than a scanner.

## Quick Start

Follow these steps to get started immediately:

- [ ] Run clark init to set up your environment.
- [ ] Run clark scan ./documents/ --mode healthcare to scan your files.
- [ ] Run clark review to inspect the findings.
- [ ] Run clark redact ./documents/ to produce clean, redacted copies.
